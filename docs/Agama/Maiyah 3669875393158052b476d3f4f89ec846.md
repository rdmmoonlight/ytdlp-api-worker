# Maiyah

- Bikin sinau bareng, tidak perlu besar, 5-7 orang. Tidak usah direncanakan, yg penting ngumpul. Nanti hidayah allah akan datang sendiri. Tidak usah mencapai apa2, tidak ngajar, yg penting sinau bareng.
- Mbah Nun mengannggap Maiyah mati saat beliau meninggal.
- Ajari anak 4 hal substansial. 1. Akhlak 2. Disiplin, 3. Akuntansi, 4. Teknologi.
