## Prinsip Utama

- Jangan ikut ritme musuh.
- Buat musuh yang harus menyesuaikan ritme kita.

## Saat Lane Lain Kalah

- Refleks salah: langsung lari def.
- Langkah benar: push lane sendiri keras → musuh terpaksa balik.
- Musuh tidak bisa menyerang dan bertahan sekaligus.

## Bahaya Def Berlebihan

- Def lane $\exp \rightarrow$ lane sendiri kosong, wave menumpuk, tower ikut tertekan.
- Def 2 lane sekaligus → kerja dua kali, hasil nol.
- Def sampai base tower → momentum hilang total.

## Tower yang Bisa Dilepas

- Tier 1 & 2: boleh dikorbankan asal ada kompensasi (misalnya tower musuh jatuh).
- Tier 3 (base): tidak boleh jatuh, game hampir pasti selesai.

## Kapan Boleh Def

- Hanya dua kondisi:

Base tower terancam.
Tim sedang kumpul untuk objektif (Lord/Turtle).

- Selain itu → terus push.

## Saat 2 Lane Kalah

- Tetap push lane sendiri → paksa musuh pecah fokus.
- Ambil objektif (Lord/Turtle) sebagai kompensasi.
- Rotate ke lane yang masih bisa diselamatkan.
- Lane yang sudah sekarat → lepaskan.

## Inti Masalah Def Berlebihan

- Refleks visual: tower diserang → ingin langsung lindungi.
- Tekanan sosial: teman panik ping def.
- Kesadaran bahwa push lebih efisien daripada def = ciri pemain macro sejati.
