# SOP Mobile Legend

## 1. Prinsip Dasar

Ranked = evaluasi kinerja
Disiplin > skill
Fokus: tidak melakukan kesalahan

## 2. Hero & Role

Role: Marksman (Gold Lane)
Hero: maksimal 3 (Miya/Lesley/Granger)
Gunakan hero yang sudah dikuasai

## 3. Alur Main Harian

1-2 Classic (pemanasan)
↓
3-5 Ranked

## 4. Session Rules (WAJIB)

Max 5 Ranked / hari
Kalah 2x berturut → STOP

## 5. Core Gameplay Rules (INTI)

1. Tidak lihat 2 musuh → mundur
2. Tidak bisa hit aman 2 detik → mundur
3. Death maksimal 3

## 6. Prinsip Marksman

Farming > war
Turret > kill
Hidup > damage
Posisi selalu di belakang

## 7. Aturan Fight

Masuk fight hanya jika:

- Musuh sudah terpisah
- Posisi aman (di belakang)
- Skill musuh sudah keluar

Selain itu:
→ jangan ikut

## 8. Target Match

Death $\leq 3$
Tidak mati di late game
Win/lose bukan fokus utama.

## 9. Kondisi Wajib

Tidak main jika:

- emosi negatif
- lelah
- koneksi buruk

## 10. Larangan Fatal

- Kejar kill masuk turret
- War saat kalah jumlah
- Buka map sendirian
- Main saat tilt

### 11. Mengapa Sistem ML Begitu

Matchmaking
Mobile Legends: Bang Bangdirancang
untuk:

- menarik pemain ke **WR sekitar 50%**
- jika performa rendah → sistem memberi lawan lebih mudah
- jika performa tinggi → lawan lebih kuat

Namun
jika pemain **tidak bisa
memanfaatkan match mudah**, WR tetap rendah.

## Sistem Evaluasi (Simple)

Setelah match:
✓ Death $\leq 3$
✓ Tidak maksa war
✓ Mundur saat tidak aman

Jika 3 ✓ :
Match = BENAR

## Kesimpulan

Ini SOP minimal, fokus, dan bisa dijalankan
Tidak ada yang berlebihan
Semua langsung berdampak ke WR
